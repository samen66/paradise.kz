# B2C Storefront — Дизайн-спецификация

> Цель: превратить текущий функциональный, но базовый B2C-сторфронт в **премиальный интернет-магазин мебели** в стиле Divan.ru, как описано в [b2Cwebsite.md](file:///Users/samenuatkhan/PhpstormProjects/paradise.kz/b2Cwebsite.md).

## Дизайн-принципы

- **Тёплый минимализм** — бежево-кремовая палитра, много воздуха, мебель как главный герой
- **Сдержанная элегантность** — никаких ярких цветов, акценты — через фото и типографику
- **Микро-анимации** — каждое взаимодействие даёт тактильную обратную связь
- **Mobile-first** — одинаково красиво на телефоне и десктопе

## Текущая база (что уже хорошо)

Палитра (`globals.css`) уже правильная: `--color-surface: #f5f3f1`, `--color-panel: #efe7dd`, `--color-ink: #404040`, `--color-mint: #d8f0e2`. Шрифты Golos Text + Manrope подходят. Компоненты функционально полные. Tailwind v4 с `@theme` готов.

## Этап 1 — Дизайн-система (UI-kit компоненты)

### Цель
Создать набор переиспользуемых компонентов, которые будут использоваться на всех страницах.

### Новые компоненты

#### `Button.tsx`
- Варианты: `primary` (bg-ink, text-white), `secondary` (border-ink, text-ink), `ghost` (text-ink, no border), `danger` (sale цвет)
- Размеры: `sm`, `md`, `lg`
- Состояния: `loading` (спиннер вместо текста), `disabled`
- Анимация: `transition-all duration-200`, лёгкое `scale-[0.98]` при нажатии (`active:scale-[0.98]`)
- Скругление: `rounded-xl` (12px)

#### `Badge.tsx`
- Варианты: `default` (bg-black/5), `mint` (bg-mint), `sale` (bg-sale), `outline`
- Pill-форма: `rounded-full px-2.5 py-1 text-xs`

#### `Input.tsx` / `Textarea.tsx`
- Стиль: `rounded-xl border border-line bg-white px-4 py-3`
- Фокус: плавный transition бордера → `border-ink` (не `border-line-strong`)
- Label сверху, hint снизу
- Поддержка ошибок: красная обводка + текст ошибки

#### `Chip.tsx` (пилюля-фильтр)
- Для фильтров каталога: «Со скидкой», «В наличии», «Доставим быстро»
- Состояния: active (bg-ink text-white) / inactive (border-line bg-white)
- Анимация переключения

#### `Modal.tsx` / `Drawer.tsx`
- Для мобильных фильтров, бургер-меню
- Backdrop blur + fadeIn, контент slideUp (мобильный) или slideRight (десктоп)
- Закрытие по backdrop click, Escape, свайпу вниз

#### `Skeleton.tsx`
- Загрузочные плейсхолдеры для карточек, текста, изображений
- Pulse-анимация на `bg-card`

#### `Toast.tsx`
- «Товар добавлен в корзину», «Заказ оформлен»
- slideIn снизу справа, автоскрытие через 3 сек
- Иконка + текст + кнопка закрытия

### Анимация-утилиты (`globals.css`)

```css
@keyframes fade-in    { from { opacity: 0 } to { opacity: 1 } }
@keyframes slide-up   { from { transform: translateY(12px); opacity: 0 } to { transform: none; opacity: 1 } }
@keyframes slide-down { from { transform: translateY(-12px); opacity: 0 } to { transform: none; opacity: 1 } }
@keyframes scale-in   { from { transform: scale(0.95); opacity: 0 } to { transform: none; opacity: 1 } }

.animate-fade-in  { animation: fade-in 0.3s ease-out }
.animate-slide-up { animation: slide-up 0.4s ease-out }
```

#### Тематические подборки
- Большие карточки-баннеры с фото, названием коллекции и стрелкой-ссылкой

## Этап 9 — Анимации и переходы

### View Transitions (Next.js App Router)
- Плавный fade при переходах между страницами
- Product card → Product detail: морфинг изображения (если поддерживается)

### Scroll Reveals
- Секции на главной: `animate-slide-up` при появлении в viewport (Intersection Observer)
- Staggered animation: карточки товаров появляются с задержкой 50ms каждая

### Hover-эффекты
- Все кнопки: `active:scale-[0.98]` для тактильности
- Ссылки: underline → no-underline (или наоборот), transition 200ms
- Карточки товаров: подъём тени `hover:shadow-md`

### Loading states
- Skeleton-загрузка для каталога (пульсирующие плейсхолдеры)
- Shimmer-эффект на картинках при загрузке

### Корзина
- Добавление товара: кнопка меняет иконку на checkmark на 1 сек
- CartBadge: bounce-анимация при изменении количества
